# КТ 1 — Каталог и карточка товара

Тестируемое приложение — [Hexlet Products Store](https://products-store.hexlet.app/).

## Подготовка

1. Откройте приложение по ссылке выше и выполните сценарии вручную. В инструкции используются названия элементов на английском языке.
2. Нажмите **Fork** в GitHub. Клонируйте свой форк.

### Подготовка проекта

```bash
git switch -c checkpoint-solution
npm ci
npx playwright install chromium
```

## Задания

### Задание 1. Поиск товара

В [pages/CatalogPage.js](pages/CatalogPage.js) реализуйте метод `search(query)`. В [tests/01-catalog.spec.js](tests/01-catalog.spec.js) дополните тест `Задание 1`.

**Контракт метода.** На странице каталога введите переданную строку в поле поиска. Метод должен работать для разных значений `query`.

**Сценарий.**

1. Начните с каталога без фильтров. Убедитесь, что среди карточек есть `Apple`.
2. Вызовите `search('Red Lipstick')`.
3. Дождитесь обновления списка через утверждения Playwright.

**Что проверить.** Карточка `Red Lipstick` видна, а в каталоге больше нет карточки `Apple`. Проверяйте карточки товаров, включая результат с нулевым количеством совпадений для `Apple`.

### Задание 2. Фильтр по бренду

В [pages/CatalogPage.js](pages/CatalogPage.js) реализуйте метод `selectBrand(brand)`. В [tests/01-catalog.spec.js](tests/01-catalog.spec.js) дополните тест `Задание 2`.

**Контракт метода.** В группе **Brand** включите чекбокс с точным названием из параметра `brand`. Если нужный чекбокс уже отмечен, оставьте его отмеченным.

**Сценарий.**

1. Откройте каталог без фильтров. Убедитесь, что карточка `Apple` присутствует.
2. Вызовите `selectBrand('Essence')`.

**Что проверить.** Чекбокс `Essence` отмечен, карточка `Essence Mascara Lash Princess` видна, карточка `Apple` отсутствует.

### Задание 3. Переход в карточку

В [pages/CatalogPage.js](pages/CatalogPage.js) реализуйте метод `openProduct(name)`. В [tests/01-catalog.spec.js](tests/01-catalog.spec.js) дополните тест `Задание 3`.

**Контракт метода.** Найдите в каталоге карточку по переданному названию и перейдите по её ссылке. Выбирайте кликабельную часть с названием товара. Кнопка **Add to cart** выполняет другое действие.

**Сценарий.**

1. Начните с каталога без поиска и фильтров.
2. Вызовите `openProduct('Red Lipstick')`.

**Что проверить.** Адрес страницы заканчивается на `/products/4`. На странице есть видимый заголовок `Red Lipstick`.

### Задание 4. Следующая страница каталога

В [pages/CatalogPage.js](pages/CatalogPage.js) реализуйте метод `nextPage()`. В [tests/01-catalog.spec.js](tests/01-catalog.spec.js) дополните тест `Задание 4`.

**Контракт метода.** Нажмите верхнюю ссылку **Next**. В каталоге две ссылки с этим названием, по одной над списком и под ним.

**Сценарий.**

1. На первой странице каталога без фильтров убедитесь, что карточка `Essence Mascara Lash Princess` видна.
2. Вызовите `nextPage()`.

**Что проверить.** Карточка `Essence Mascara Lash Princess` исчезла из списка. После обновления видна хотя бы одна карточка товара. Для этого сценария результат определяется по списку карточек.
