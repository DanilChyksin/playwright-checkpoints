# КТ 1 — Каталог и карточка товара

Используйте английский интерфейс и начинайте каждый сценарий в новом контексте Playwright. Работайте с магазином через браузер. Используйте локаторы Playwright и утверждения с автоматическим ожиданием.

## Задания

1. **`search(query)`**. Ввести переданный текст в строку поиска каталога. В тесте найти `Red Lipstick` и убедиться, что карточка `Apple` исчезла.
2. **`selectBrand(brand)`**. Включить чекбокс переданного бренда. В тесте выбрать `Essence` и проверить, что тушь видна, а `Apple` отсутствует.
3. **`openProduct(name)`**. Открыть карточку по названию. В тесте открыть `Red Lipstick` и проверить адрес `/products/4` и заголовок товара.
4. **`nextPage()`**. Нажать верхнюю ссылку `Next`. В тесте дождаться обновления списка, проверить, что он не пуст и товар с первой страницы исчез.

## Структура проекта

- `pages/CatalogPage.js` — реализуйте четыре асинхронных метода класса `CatalogPage`. Сохраните именованный экспорт, имена методов и аргументы.
- `tests/01-catalog.spec.js` — напишите четыре теста, по одному на задание. Названия тестов начинаются с `[1]`, `[2]`, `[3]`, `[4]` соответственно. Вызовите соответствующий метод Page Object и проверьте результат через `expect`.
- `playwright.config.js` — конфигурация Chromium и адрес магазина.

Стартовый набросок каждого теста содержит вызов метода. Допишите подготовку данных и проверки по условию. Закрытая проверка вызывает методы с другими данными и проверяет результат в браузере. Темы этой работы — локаторы, действия и события, утверждения, Page Object Model и структура тестов. Для корзины нужна изоляция состояния между сценариями.
