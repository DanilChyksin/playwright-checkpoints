# Контрольные точки по Playwright

Приложение — [Hexlet Products Store](https://products-store.hexlet.app/).

1. [Каталог и карточка товара](01-catalog/README.md)
2. [Корзина](02-cart/README.md)

Сделайте Fork, клонируйте его и создайте отдельную ветку для каждой контрольной точки. Выполните четыре задания в соответствующей папке. Для каждой точки откройте отдельный pull request из своего форка в исходный репозиторий, приложите ссылку на него в Moodle. Вкладка Actions показывает результаты открытого запуска. Оценка преподавателя формируется по закрытому запуску для указанного коммита.

Для каждой точки используйте Node.js 22, затем выполните из её папки:

```sh
npm install
npx playwright install chromium
npm test
```

В стартовом проекте тесты падают, пока вы не реализуете задания.
