# КТ 2 — Корзина

Тестируемое приложение — [Hexlet Products Store](https://products-store.hexlet.app/).

## Подготовка

1. Откройте приложение по ссылке выше и выполните сценарии вручную. В инструкции используются названия элементов на английском языке.
2. Нажмите **Fork** в GitHub. Клонируйте свой форк.

### Подготовка проекта

```bash
git switch -c checkpoint-solution
npm ci
npx playwright install chromium
```

## Задания

Каждый сценарий начинается в каталоге с пустой корзиной. В заданиях 3 и 4 подготовьте товары в том же тесте, где будете удалять или очищать. Для подготовки можно нажать **Add to cart** внутри нужной карточки каталога и затем открыть корзину по ссылке **Cart**. При поиске товара в корзине ориентируйтесь на строку товара с его названием и действием **Delete**.

### Задание 1. Добавление товара

В [pages/CartPage.js](pages/CartPage.js) реализуйте метод `addProduct(name)`. В [tests/02-cart.spec.js](tests/02-cart.spec.js) дополните тест `Задание 1`.

**Контракт метода.** Находясь в каталоге, откройте карточку с переданным названием и нажмите **Add to cart** на странице самого товара. Метод заканчивается на странице товара.

**Сценарий.**

1. Из каталога вызовите `addProduct('Red Lipstick')`.
2. В самом тесте перейдите в корзину через ссылку **Cart** в шапке.

**Что проверить.** В корзине видна строка `Red Lipstick`. Проверка строки подтверждает действие после перехода со страницы товара.

### Задание 2. Открытие корзины

В [pages/CartPage.js](pages/CartPage.js) реализуйте метод `open()`. В [tests/02-cart.spec.js](tests/02-cart.spec.js) дополните тест `Задание 2`.

**Контракт метода.** Нажмите ссылку **Cart** в шапке магазина.

**Сценарий.**

1. Начните с каталога. Оставьте корзину пустой.
2. Вызовите `open()`.

**Что проверить.** Адрес заканчивается на `/cart`, видна ссылка **Continue shopping**.

### Задание 3. Удаление одной позиции

В [pages/CartPage.js](pages/CartPage.js) реализуйте метод `removeProduct(name)`. В [tests/02-cart.spec.js](tests/02-cart.spec.js) дополните тест `Задание 3`.

**Контракт метода.** На странице корзины найдите строку товара с переданным названием и нажмите **Delete** именно внутри этой строки.

**Сценарий.**

1. Добавьте из каталога `Red Lipstick` и `Apple` по одному разу.
2. Откройте корзину и проверьте, что видны обе строки.
3. Вызовите `removeProduct('Red Lipstick')`.

**Что проверить.** Строки `Red Lipstick` больше нет, а строка `Apple` по-прежнему видна.

### Задание 4. Очистка корзины

В [pages/CartPage.js](pages/CartPage.js) реализуйте метод `clear()`. В [tests/02-cart.spec.js](tests/02-cart.spec.js) дополните тест `Задание 4`.

**Контракт метода.** На странице заполненной корзины нажмите кнопку **Clear cart**.

**Сценарий.**

1. Добавьте из каталога `Red Lipstick` и `Apple` по одному разу.
2. Откройте корзину и проверьте, что видны обе строки. Это подтверждает, что корзина заполнена до очистки.
3. Вызовите `clear()`.

**Что проверить.** Строки `Red Lipstick` и `Apple` отсутствуют. Оба утверждения выполните после вызова метода.

## Как проверить и сдать

1. Запустите все четыре сценария командой `npm test`. Чтобы наблюдать действия браузера, запустите `npm test -- --headed`. Чтобы запустить один сценарий, используйте фильтр по имени, например `npm test -- --grep "Задание 1"`.
2. Перед сдачей убедитесь, что каждый тест содержит проверки из раздела «Что проверить» для соответствующего задания. Стартовые заготовки содержат вызовы методов. Оценка включает проверку поведения методов и проверку утверждений в вашем PR.
3. Сохраните изменения в коммите и отправьте свою рабочую ветку в форк. Откройте pull request из этой ветки в `main` **исходного репозитория этой контрольной точки**.
4. Проверьте результат открытого workflow во вкладке **Checks** вашего PR. Сдайте в Moodle ссылку на PR.
